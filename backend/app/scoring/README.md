# Оценка риска

Логистическая регрессия по 13 признакам из внешних источников и заявки:
вероятность дефолта за 12 месяцев и вклад каждого признака.

Модель обучена исключительно на синтетическом наборе кредитных заявок.
Реальные клиентские, банковские и персональные данные при обучении не
использовались. Полученные метрики характеризуют демонстрационный датасет и не
должны интерпретироваться как качество промышленной банковской модели.

- `features.py` — расчёт признаков; один и тот же код используется при обучении и в конвейере;
- `model.json` — медианы для пропусков, параметры стандартизации, коэффициенты и метрики на отложенной выборке;
- `inference.py` — `score(raw)`: PD, версия модели и факторы с пояснениями для клиента.

Скрипт обучения ожидает синтетический датасет в
`data/applications.csv`; зависимости перечислены в `ml/requirements.txt`.
Готовый артефакт `model.json` уже включён в репозиторий.

```bash
python ml/scoring/train.py data/applications.csv
```

Скрипт печатает метрики, калибровку по децилям, доли классов риска и перезаписывает `model.json`.
