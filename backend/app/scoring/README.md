# Оценка риска

Логистическая регрессия по 13 признакам из внешних источников и заявки: вероятность дефолта за 12 месяцев и вклад каждого признака.

- `features.py` — расчёт признаков; один и тот же код используется при обучении и в конвейере;
- `model.json` — медианы для пропусков, параметры стандартизации, коэффициенты и метрики на отложенной выборке;
- `inference.py` — `score(raw)`: PD, версия модели и факторы с пояснениями для клиента.

Переобучить из корня репозитория (зависимости — `ml/requirements.txt`, датасет `data/applications.csv`):

```
.venv\Scripts\python ml\scoring\train.py
```

Скрипт печатает метрики, калибровку по децилям, доли классов риска и перезаписывает `model.json`.
