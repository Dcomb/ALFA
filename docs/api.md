# Программный интерфейс и контракты

Полный машинный контракт формируется FastAPI и доступен после запуска:

- интерактивная документация Swagger: `http://localhost:8000/docs`;
- машиночитаемый OpenAPI-контракт: `http://localhost:8000/openapi.json`;
- коллекция запросов Postman: `docs/alfa-api.postman_collection.json`.

Основные группы:

| Группа | Методы | Назначение |
| --- | --- | --- |
| Клиенты | `GET /clients`, `POST /clients/register`, `GET /me` | демо-вход, регистрация и профиль |
| Рекомендации | `GET /ranking/products`, `POST /ranking/recommend` | каталог и персональный подбор |
| Калькуляторы | `POST /ranking/calculator/payment`, `POST /ranking/calculator/limit` | платёж и доступный лимит |
| Заявки | `GET/POST /applications`, `GET/PATCH /applications/{id}` | создание, список и изменение |
| Конвейер | `submit`, `process`, `accept`, `decline-offer`, `withdraw`, `finalize` | допустимые переходы заявки |
| Документы | `GET/POST /applications/{id}/documents` | список и загрузка подтверждений |
| Ассистент | `POST /chat` | диалог LangGraph с вызовом инструментов |
| Банк | `GET /bank/applications` | журнал для роли банка |

Клиентские методы требуют `X-Client-Id`; банковские — `X-Role: bank`.
Это демонстрационный механизм, а не промышленная аутентификация. Все входные
модели запрещают неизвестные поля там, где это критично, и возвращают HTTP 422
при нарушении контракта.

Регистрация сохраняет ОГРН и дату регистрации в профиле клиента. При создании
заявки backend дополнительно фиксирует `client_snapshot` и `credit_snapshot`:
снимок реквизитов компании и выбранных условий кредита. Поэтому открытая из
истории заявка показывает данные, действовавшие в момент её оформления, даже
если профиль или каталог продуктов позднее изменились.

## Принципы API

- клиент видит только собственные заявки и документы;
- операции смены статуса проходят через кредитный конвейер;
- неизвестная заявка возвращает HTTP 404;
- конфликт состояния возвращает HTTP 409;
- ошибка структуры запроса возвращает HTTP 422;
- внутренние исключения и технические трассировки не передаются клиенту;
- OpenAPI формируется непосредственно из фактических маршрутов и схем.

## Основные заголовки

| Заголовок | Где применяется | Пример |
| --- | --- | --- |
| `X-Client-Id` | клиентские операции | `demo_cafe` |
| `X-Role` | банковский журнал | `bank` |
| `Content-Type` | JSON-запросы | `application/json` |

При загрузке документов используется `multipart/form-data`. Максимальный
размер одного файла — 10 МБ. Поддерживаются PDF, TXT, CSV, Markdown, DOCX и
XLSX.
