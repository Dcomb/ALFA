# Тестовые сценарии

1. ИП без залога: подобрать финансирование кассового разрыва, открыть детали,
   убедиться, что ассистент объясняет выбранную карточку без повторных вопросов.
2. ООО с активами: выбрать залоговый сценарий, подать заявку директором и
   получить решение с учётом обеспечения.
3. Молодой бизнес: проверить ограничения по сроку деятельности.
4. Недоступность БКИ: заявка остаётся на проверке, решение не выдумывается.
5. Стоп-факторы: ликвидация, просрочка и дисквалификация дают отказ с причиной.
6. Серая зона: ИП получает вариант с поручительством МСП, ООО - залоговый
   контроффер; выбранный вариант переводит заявку в статус «Одобрена».
7. Документы: расхождение переводит заявку в статус «Нужны данные»; после
   загрузки PDF, DOCX и XLSX доступны инструменту ассистента как данные, а не
   инструкции.
8. Риск без заявки: вопрос о риске компании вызывает инструмент
   `assess_company_risk` и различает вероятность дефолта и юридическое
   банкротство.
9. Изоляция: при переключении демо-профиля список заявок очищается и загружается
   только для нового `client_id`; история ИИ-чатов также раздельная.
10. Регистрация: новый ИНН создаёт кабинет; повторный ИНН возвращает 409.

Команды запуска перечислены в корневом README. Модульные и интеграционные тесты
backend используют базу `alfa_test`, а системные тесты — `alfa_system_test`
через отдельный сервис `backend-test`.
